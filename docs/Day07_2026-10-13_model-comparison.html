Model comparison

Overview

There are many options and different criteria for model comparison. Here, we show a few popular methods in ecological research. Remember, all things equal, the simpler model is preferred over any more complex alternative. This is known as the ”principle of parsimony”.

The Akaike Information Criterion (AIC) allows for model comparison and selection considering both the fit of the model (rewarded) and the number of parameters estimated (penalized). Here, we will use AIC-based selection methods to identify the top model in a set of candidate models.

Getting started

In a telemetry study, wolverines (Gulo gulo) were monitored to determine factors influencing survival. Animals were live-trapped, equipped with a GPS transmitter, and released. For each tagged individual, the researchers recorded the sex, age, personality (based on behavior in the trap), and an index for the abundance of reindeer in the area used by the animal. They then recorded whether the animal was still alive after 1 year of monitoring.

Step-wise selection based on parsimony

With AIC-based model selection, the goal is to find the model (or group of models) with the lowest AIC-value(s). The absolute value itself is not important.

Note also, that you can only use AIC to compare models fitted to the same data set!

Step-wise selection based on parsimony

We can use the stepAIC() function in the MASS library to do a step-wise selection of terms, shown next.

In each step, the function removes the term whose removal results in the lowest AIC value. Once no more terms can be removed without a reduction in AIC, the procedure stops and returns the top model.

You could display the terms included in the top model and check the output of the top model using summary() and formula().

A-priori candidate models: frequentist

A drawback of the step-wise selection process is that, due to the sequential removal (or addition) of terms, a predictor may be dropped from a more complex model when it is actually important in the simpler model. As an alternative to the step-wise selection procedure, you can build multiple candidate models and then compare these using AIC (or WAIC in the next example).
